# Cybersecurity Awareness Chatbot 🛡

A modular C# Console Application designed to educate users on essential cybersecurity practices. Developed as a POE for Rosebank College.

## 📋 Features
* Multimedia voice-over greeting.
* User authentication and personalized sessions.
* 10-point security advice database.
* Professional ASCII interface.

##  Technical Stack
* Language: C# (.NET 10.0)
* Version Control: Git & GitHub

##  Class Structure
* Program.cs (Main Controller)
* AudioPlayer.cs (Multimedia)
* User.cs (Data Capture)
* Chatbot.cs (UI & Advice Logic)
